## How to run

You need a C compiler like GCC.

```bash
git clone https://github.com/rajbhowmik-code/SPL-1-1-SF.git
cd SPL-1-1-SF
gcc <file>.c -o <file>
./<file>
```

On Windows, run `<file>.exe` instead of `./<file>`.
